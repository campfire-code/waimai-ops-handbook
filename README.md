# 外卖经营方法论手册

> 外卖、选址、抖音同城、开店的经营方法论资料包（已脱敏）。篝火出品，版本 0.1.0。

覆盖从「想开店」到「把店经营好」的主线：创业前规划与餐饮类型、选址与商圈、市场调研、财务模型、外卖平台运营、抖音同城营销、连锁加盟与谈判、复购诊断，以及商家后台日常巡检 SOP 和数据使用纪律。

## 怎么读

- 在线读：按下面的目录点开 `handbook/` 里的章节。
- 离线读 / 打印：仓库里的 `外卖经营方法论手册.pdf` 是全部章节合并后的版本。
- 准备开店：按第 2 → 3 → 4 → 5 章读；已经在做外卖：直接读第 6、9、10 章。每章末尾有核对清单。

## 重要说明

- **平台规则以平台为准**：手册中关于美团、抖音等平台的产品名称、指标、规则和后台入口，都来自整理时的经验陈述，平台更新频繁，请以平台当前官方规则和后台页面为准。
- **数字是经验值**：比例、阈值、周期只是参考，不是统计结论，也不是对任何门店结果的承诺。
- **不构成专业建议**：涉及证照、合同、合伙、税务，请咨询专业人士，并以当地法规为准。
- **已脱敏**：不含任何具体门店、客户、人名、城市、金额数据和原始录音内容。
