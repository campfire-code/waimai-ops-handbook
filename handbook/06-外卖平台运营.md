# 外卖平台运营

> 本章涉及的平台产品名称、指标、规则和比例，来自整理时的经验陈述，**一律以平台当前官方规则和商家后台为准**。平台规则更新频繁，请不要把这里的内容当作最新规则。

## 一、总体判断

来源材料给出的几点趋势判断（均为经验陈述，未逐条核实，请以平台公告为准）：

- 平台补贴大战之后，运营回归理性，**精细化运营**成为关键；
- 平台有一批考核指标，其中对商家影响最大的几项是：**非接单率、差评率、实收上报率（真实交易数据）**；
- **提升复购率有三个抓手：产品、服务、价格。**

## 二、推广体系

核心原则：**所有推广都要拿投产比（花出去的钱换回多少实收）来比较，不要凭感觉。**

| 推广方式（名称以平台为准） | 要点 |
|---|---|
| 精准类搜索推广（常称「点金」类） | 最精准的推广方式，其他推广都应当与它比投产比 |
| 展位类推广 | 作为补充手段，在商家列表占更大面积 |
| 全站类推广 | 划算就用，不划算就不用，没有玄学 |

### 预算

- 按实收比例调整；来源经验是推广花费一般占实收的 2%～5%（经验值，需结合自己的毛利核实）。

### 定向人群

不同阶段，加不同的人群：

| 人群 | 什么时候加 |
|---|---|
| 新客 | 开店初期重点投 |
| 老客 | 数据下滑时加，把摇摆的顾客拉回来 |
| 流失老客 | 长假休息后复工时、大改菜单后加 |

## 三、评分与评价

- **求好评比删差评更重要。** 恶意差评其实是少数，更大的提升来自把正常顾客的好评多拿到；
- **邀评发券**：设置评价后得券，券要有吸引力，不要只是一两元的小券；
- **超预期法**：把一个月的赠品集中在一周内送完，制造视觉冲击，促使顾客拍照、分享、写出高质量的评价；
- **视觉冲击法**：赠品本身不值钱，但数量多、能铺满一桌，触发拍照分享欲；
- **收集欲法**：设计带稀有款的小赠品，触发顾客的收集欲和炫耀欲，带动复购。

> 注意：评价激励必须符合平台规则，不能采用被平台禁止的方式（例如虚构评价）。以平台规则为准。

## 四、非接单率

- 平台非常在意商家的**不接单情况，目标是接近 0**；
- 「不接单」不只是拒单，还包括：接单后缺货退单、超时未接单；
- 平台缺的是流量和履约，不是商家数量。浪费平台流量的店，会被降低曝光；
- 准时类的保障服务按平台说明开启，并确认不影响流量。

## 五、客单价与定价

- **高客单价品类**天然单量少，需要做**单人份**的产品来突破；
- 用一部分「福利品」（小吃、甜品、饮品等），来拉升客单价和利润，来源经验认为其占比约 30%（经验值）；
- **低客单价品类**要靠附加品赚钱。

## 六、流量与权重

- 店铺权重越高，同样的推广花费越划算；
- **双转化率**——入店率和下单率——是核心指标；
- 为平台留住老客、减少客诉、提高流量利用率，平台会倾向于给更多流量；
- 线下发传单有时比线上流量更便宜，值得对比测算。

## 七、数据真实性

- 如果依赖补贴型的拉新活动才有流量，一旦停掉流量就掉，说明**店铺基础有问题**；
- 不真实的数据会带来「搜索流量看似很高、列表流量却很低」之类的异常；
- 新客下单率不合格时，应当**调整菜单**，而不是靠活动硬撑。

## 八、核对清单

- [ ] 各类推广都按投产比比较过
- [ ] 推广预算按实收比例设置
- [ ] 不同阶段使用了不同的定向人群
- [ ] 邀评券有吸引力，评价激励合规
- [ ] 非接单率保持在平台要求内
- [ ] 高客单品类有单人份产品，附加品已规划
- [ ] 新客下单率不合格时先查菜单，不依赖活动
