# 复购诊断与经营节奏

## 一、用漏斗看门店

把顾客从陌生到长期复购，分成六个阶段，用来定位门店卡在哪里：

| 阶段 | 含义 |
|---|---|
| A0 | 未接触 |
| A1 | 曝光 |
| A2 | 进店、看菜单 |
| A3 | 首次购买 |
| A4 | 复购 |
| A5 | 长期复购 |

来源经验：很多靠话题或打卡走红的门店，卡在 **A3**——有首购，但没有形成复购的基本盘。

## 二、几个关键判断

1. **下沉市场不能照搬一线城市的「漂亮饭」。** 品类小众、人口基数和消费习惯不同，首购的流量不等于复购的基本盘。
2. **长期经营必须回到「日常基本款」。** 顾客不知道吃什么的时候，能自然想起你，而不是只适合打卡一次。
3. **投流不能替代基本盘。**

## 三、调整的顺序

按下面的顺序做，不要倒过来：

1. 菜单工程与品类适配；
2. 单人场景和复购产品；
3. 稳定的内容节奏；
4. 付费投流放大。

## 四、春节等长假的节奏

- 长假期间继续营业的商家不在少数，竞争激烈；
- 长假后复工时，**要给流失老客加定向**（见第 6 章），把休息期间流失的顾客找回来；
- 提前规划放假与复工时间，避免临时关店对数据造成影响。

## 五、新赛道的提醒

即时零售（例如闪电仓一类）是近年出现的新机会。来源提到宠物类用品等品类表现较好，但属于个别经验，**进入前请自行用数据验证品类、竞争和平台政策**。

## 六、核对清单

- [ ] 已判断门店卡在漏斗的哪一环
- [ ] 菜单、单人产品、复购产品已按顺序调整
- [ ] 内容更新有稳定节奏
- [ ] 长假后复工有找回老客的预案
