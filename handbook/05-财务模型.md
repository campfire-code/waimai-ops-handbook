# 财务模型

> 本章的比例、周期是经验参考值。公式需要你代入本地的真实数据，结果仅用于决策参考。

## 一、盈亏平衡点

**公式：**

```
日盈亏平衡营业额 =（月房租 + 月人工 + 月杂项）÷ 毛利率 ÷ 30 天
```

关键提示：**所有成本必须全额计入，不能遗漏**——例如平台佣金、水电、折旧、各类杂费，都要算进去。漏算会让整个测算失去意义。

## 二、营业额预估

两种方法，建议两种都做并对比。

### 方法 A：竞品对比法

1. 选择**可比**的竞争对手：同动线、同品类、同面积、同客单价；
2. 获取其营业数据（方法见第 4 章）；
3. 调整差异系数：位置系数 × 产品系数 × 竞品系数；
4. 得出预估营业额，并给出**天花板值、平均值、地板值**三个版本。

### 方法 B：人流转化法

```
营业额 = 日均人流量 × 进店转化率 × 客单价 × 营业天数
```

进店转化率的经验参考区间约为 3%～8%（快餐偏高，正餐偏低），请用实地数据校准。

## 三、安全边际

```
安全边际率 =（预估营业额 − 盈亏平衡营业额）÷ 预估营业额
```

| 安全边际率 | 判断 |
|---|---|
| 大于 20% | 低风险 |
| 10%～20% | 需要优化成本 |
| 小于 10% | 高风险 |

做决策时，用**地板值**来算安全边际，比用平均值更保守、更安全。

## 四、回本周期的参考标准

来源经验中的标准如下，超出需要重新评估：

| 类型 | 回本周期参考 |
|---|---|
| 小吃店 | 3 个月以内 |
| 刚需 / 轻社交店 | 6～8 个月 |
| 社交型店 | 8 个月以内 |

注意：不同类型、不同地区、不同年份的回本周期差异很大，来源提到某些加盟类型的回本周期近年有明显延长，请以最新的实际情况为准，不要机械套用。

## 五、核对清单

- [ ] 成本项全额计入，没有漏项
- [ ] 已用至少两种方法预估营业额，并给出三个版本
- [ ] 营业额已扣除淡季（寒暑假、节假日等）
- [ ] 安全边际率按地板值算过
- [ ] 回本周期在参考标准内，否则已重新评估
