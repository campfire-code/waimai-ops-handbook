# 如何使用本手册

## 这本手册讲什么

这是一份面向餐饮外卖从业者和准备开店的人的经营方法论手册，覆盖从「想开店」到「把店经营好」的主线：

| 章节 | 解决的问题 |
|---|---|
| 第 2 章 创业前规划与餐饮类型 | 我适不适合开店、开什么类型的店 |
| 第 3 章 选址与商圈 | 店开在哪里、怎么评价一个铺位 |
| 第 4 章 市场调研与竞争分析 | 怎么摸清周边的真实生意 |
| 第 5 章 财务模型 | 能不能赚钱、多久回本、风险多大 |
| 第 6 章 外卖平台运营 | 平台上怎么做推广、评价、定价和流量 |
| 第 7 章 抖音同城营销 | 怎么用本地短视频给门店引流 |
| 第 8 章 连锁、加盟与合作谈判 | 走哪条创业路径、谈判与合同要点 |
| 第 9 章 复购诊断与经营节奏 | 门店为什么没有复购、怎么调整 |
| 第 10 章 商家后台日常巡检 SOP | 每天看什么、怎么核对数据、怎么安全地操作 |
| 第 11 章 自动化与数据使用纪律 | 用工具和 AI 处理经营数据时的底线 |
| 附录 | 公式速查表、核对清单 |

## 阅读建议

- 准备开店：按第 2 → 3 → 4 → 5 章顺序读，先算清楚账再决定。
- 已经在做外卖：直接读第 6、9、10 章。
- 想做同城引流：读第 7 章。

## 使用前请先知道

1. **平台规则会变。** 手册里关于美团等平台的产品名称、指标、规则和后台入口，都来自整理时的经验，一律**以平台当前的官方规则和后台页面为准**。
2. **数字是经验值。** 手册中的比例、阈值、周期等数字（例如遮挡比例、转化率区间、回本周期），是经营经验里的参考值，不是统计结论，也不是对任何门店结果的承诺。请结合本地实际情况核实后再用。
3. **本手册已脱敏。** 不包含任何具体门店、客户、人名、城市和金额数据，案例均已改写为通用方法。
4. 手册不构成法律、税务或投资建议。涉及证照、合同、合伙、税务的事项，请咨询专业人士，并以当地法规为准。
