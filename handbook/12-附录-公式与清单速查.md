# 附录：公式与清单速查

> 所有比例、阈值均为经验参考值，请结合本地实际核实。

## 一、公式

| 名称 | 公式 |
|---|---|
| 日盈亏平衡营业额 | （月房租 + 月人工 + 月杂项）÷ 毛利率 ÷ 30 |
| 人流转化法营业额 | 日均人流量 × 进店转化率 × 客单价 × 营业天数 |
| 安全边际率 | （预估营业额 − 盈亏平衡营业额）÷ 预估营业额 |
| 推广投产比 | 推广带来的实收 ÷ 推广花费 |

## 二、经验阈值

| 项目 | 参考 |
|---|---|
| 进店转化率 | 约 3%～8% |
| 安全边际率 | >20% 低风险；10%～20% 需优化；<10% 高风险 |
| 回本周期 | 小吃店 ≤3 个月；刚需 / 轻社交 6～8 个月；社交型 ≤8 个月 |
| 遮挡物占比 | <20% 可接受；20%～40% 需补光；>40% 建议放弃 |
| 推广花费占实收 | 约 2%～5% |
| 社交型大店推广预算 | 每月约盈利的 10% |
| 竞品统计 | 连续 3 天（工作日 2 + 周末 1） |
| 商圈危险信号 | 季度关店率 >10%；新店成活率 <20% |
